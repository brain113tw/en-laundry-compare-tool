# 沂恩對比圖管理器

沂恩精緻洗衣坊使用的洗前 / 洗後案例圖製作工具。

支援照片拖曳、Before / After 對比、網站與社群尺寸、FB / IG 裁切預覽、批次輸出、慣用版型儲存，以及 WEBP / PNG / SVG 輸出。

> 本工具為純前端、本機執行工具。照片在瀏覽器本機處理，不需要 Python，不會主動上傳至外部伺服器。

---

## 功能特色

- 洗前 / 洗後照片指定
- 照片拖曳與滑鼠滾輪縮放
- 左右比例調整
- 自訂畫布尺寸
- 網站 / FB / IG 常用尺寸
- BEFORE / AFTER 標籤
- 標題、店名、背景橫條
- 元素拖曳、縮放、旋轉、鎖定
- 安全區與裁切預覽
- FB / IG 縮圖預覽
- 清晰度 / 銳利化調整
- WEBP / PNG / SVG 輸出
- 批次案例製作與 ZIP 輸出
- 慣用版型儲存
- 匯出 / 匯入設定檔
- 上一步 / 下一步

## 開始使用

### 1. 下載工具

下載專案內的 HTML 檔案，例如：

```text
en_compare_manager_v5_8.html
```

### 2. 開啟

建議使用：

- Google Chrome
- Microsoft Edge

直接雙擊 HTML 檔案即可使用，不需要安裝。

---

## 基本操作

### 加入照片

可使用：

- 上方 `加入照片`
- `加入資料夾`
- 直接將照片拖入左側照片區

支援常見格式：

- JPG / JPEG
- PNG
- WEBP
- BMP
- GIF（固定載入其中一幀）

### 指定洗前 / 洗後

在左側照片清單中，分別設定：

- `洗前`
- `洗後`

設定完成後，中間會產生即時對比預覽。

---

## 照片位置與大小

在主預覽區可以直接操作：

- 拖曳照片：調整位置
- 滑鼠滾輪：放大 / 縮小照片
- 拖曳中間分隔線：調整左右比例
- 右側數值欄：精確調整大小與位置

如果照片解析度不足，工具會顯示放大取樣提示。

---

## 常用尺寸

可使用預設尺寸，例如：

| 用途 | 尺寸 |
|---|---:|
| 網站案例圖 | 1600 × 900 |
| IG 方形 | 1080 × 1080 |
| IG 直式 | 1080 × 1350 |
| 3:4 直式 | 1080 × 1440 |
| FB 橫幅 | 1200 × 630 |
| 9:16 直式 | 1080 × 1920 |

也可自行輸入寬度與高度。

---

## BEFORE / AFTER 標籤

可調整：

- 文字內容
- 字體大小
- 文字粗細
- 文字顏色
- 框底色
- 透明度
- 圓角
- 陰影
- 位置
- 旋轉
- 鎖定

在主預覽上可直接拖曳標籤位置，並使用控制點調整大小。

標題可：

- 顯示 / 隱藏
- 改字級
- 拖曳位置
- 縮放
- 旋轉
- 鎖定

## 安全區與社群裁切預覽

工具內可預覽不同平台常見比例，提前檢查文字或主體是否可能被裁切。

包含：

- 中央 60% 安全區
- 1:1
- 3:4
- 4:5
- 1200:630
- 9:16
- 16:9

> 此功能為幾何比例模擬，不代表 Facebook 或 Instagram 在所有版位都一定以相同比例裁切。

---

## 清晰度與輸出品質

### 銳利化

可增加邊緣清晰感。

注意：

- 銳利化不是 AI 修復
- 無法補回失焦或原圖不存在的細節
- 過高可能造成邊緣過硬或雜訊增加

### WEBP 品質

可調整 WEBP 品質與檔案大小。

工具會顯示：

- 原圖像素尺寸
- 原圖檔案大小
- 輸出尺寸
- 總像素量
- 預估 / 實際輸出檔案大小

---

## 輸出格式

### WEBP

建議網站使用。

優點：

- 檔案較小
- 畫質與容量平衡佳
- 適合網站案例頁

### PNG

適合需要較穩定無損輸出的情況。

### SVG

目前 SVG 為將完成圖嵌入 SVG 容器中，屬點陣圖包裝，並非每個物件都可獨立編輯的純向量檔。

---

## 批次功能

完成一組洗前 / 洗後後，可加入批次清單。

每一組可以保留自己的：

- 圖片位置
- 圖片大小
- 標題
- 標籤
- 店名
- 輸出尺寸

也可：

- 依檔名 / 子資料夾自動配對
- 套用目前樣式到指定案例
- 勾選多組一起輸出
- 產生 ZIP

自動配對後仍建議人工確認洗前 / 洗後順序。

## 慣用版型

v5.8 支援儲存常用版型。

建議建立：

- 網站 1600×900
- IG 方形 1080×1080
- IG 直式 1080×1350
- FB 1200×630
- 鞋包案例版
- 衣物案例版

### 儲存方式

在 `我的慣用版型` 中：

1. 調好目前版型
2. 輸入名稱
3. 按 `儲存目前設定`

### 版型內容

可保存：

- 畫布尺寸
- 背景色
- 左右比例
- 標題設定
- BEFORE / AFTER 樣式
- 店名與橫條
- 元素位置
- 旋轉
- 鎖定
- 清晰度
- WEBP 品質

照片本身不會存進慣用版型。

## 建議工作流程

### 網站案例圖

1. 套用 `網站 1600×900`
2. 加入洗前 / 洗後
3. 調整主體位置
4. 修改標題
5. 檢查安全區
6. 輸出 WEBP

### IG 案例圖

1. 套用 `IG 直式 1080×1350`
2. 調整左右主體
3. 檢查 1:1 與 4:5 預覽
4. 輸出 PNG 或 WEBP

- 不需要帳號
- 不需要 Python

- 不會主動上傳照片

- 客戶照片

- 訂單資料
- API Key
- Access Token
- 資料庫密碼
- 私鑰
- 其他敏感資料

## 常見問題

### 拖曳照片沒有反應

先確認：

- 使用 Chrome 或 Edge
- 拖到左側照片區

若仍無法使用，改按 `加入照片`。

### 輸出太模糊

可嘗試：

- 使用更高解析度原圖
- 增加輸出尺寸
- 提高 WEBP 品質
- 適度增加銳利化
- 改輸出 PNG

### 文字被裁掉

使用安全區與社群裁切預覽確認位置，將重要文字移回中央區域。

### 慣用版型不見

瀏覽器本機資料可能被清除。建議定期匯出 JSON 備份。

05　我的慣用版型

會儲存目前的畫布尺寸、背景、標題、BEFORE / AFTER、店名與橫條、輸出品質等設定；不儲存照片。最多 12 組。

慣用版型優先儲存在這台電腦目前瀏覽器的本機儲存空間。若清除瀏覽器資料，可能會消失；重要版型可另外匯出 JSON 備份。

操作紀錄 / 限制

照片與批次清單只在這個分頁暫存，關閉或重新整理不保留。慣用版型不含照片。請先輸出檔案。資料夾不會被改名、覆寫或刪除。支援 JPEG / PNG / WEBP / BMP；GIF 固定載入時的一幀；HEIC 請先轉成 JPEG / PNG。

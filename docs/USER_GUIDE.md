# 沂恩圖片工具 v6.2 使用說明

## 開啟

將 ZIP 解壓縮，使用 Chrome 或 Edge 開 `index.html`。上方按「圖片工具箱・單張 / 批次」。不需 Python、BAT、後端、帳密或安裝模型。原有對比製作仍在原本工作區。請保留同一層的 `vendor` 資料夾，Chrome 與 Edge 要靠它才能開 iPhone 的 HEIC 照片。

新版工具箱採左側工具列，左邊照片清單、中間預覽、右邊目前工具設定。點「回對比工作區」可返回；兩邊共用照片清單，但各自保留自己的編輯資料。

## 快速單張流程

1. 按「加入照片」，或把照片拖進工具箱。資料夾可用「加入資料夾」。
2. 點左側縮圖，成為目前編輯照片。這不代表勾選批次。
3. 選「尺寸壓縮」，依用途選最長邊、固定畫布、百分比或原尺寸。
4. 需要轉正時用「旋轉」。需要去掉多餘邊緣時用「裁切」。
5. 到「浮水印」啟用文字，或選一張 Logo；可在成品上拖曳。
6. 有個資時到「隱私遮蔽」畫框。文字個資建議實色遮蔽。
7. 按「看成品」確認構圖與遮蔽，再按「輸出目前單張」。

## 尺寸與壓縮

「最長邊等比縮放」將原圖最長邊縮到指定尺寸；預設不放大原圖。「指定畫布寬高」固定整張成品的尺寸，圖片本身保持比例。

- 完整保留：整張照片都保留，不足處填入背景色或透明。
- 填滿：填滿畫布，部分邊緣可能被裁掉。
- 允許放大：勾選後才允許把低像素照片放大，不代表創造真實細節。

旋轉後，等比模式會用旋轉後長寬計算。對固定畫布，不會把直圖硬拉成橫圖。

輸出格式可選 WEBP、PNG、JPG。JPG 不支援本工具的透明背景，會使用所選背景色。PNG 不使用有損品質滑桿。

目標容量填 0 表示不限制；例如填 300 表示以 300 × 1024 bytes 為搜尋目標。容量搜尋只降低 JPEG / WEBP 品質至下限 40；若仍超標會提示，不會私自改尺寸。

「計算目前格式容量」會實際編碼，顯示 KB / MB 及 bytes；設定變更後會顯示待計算。尺寸與檔案容量是兩種不同的大小。

## 裁切、旋轉與一般加強

裁切工具會顯示原始方向的圖片選區，不是成品。可拉四角、拖框內移位或在框外重新畫。比例可選自由、1:1、16:9、4:5、3:4、4:3。按「完成選區 → 看成品」檢查結果。

改變比例時會保留已經畫好的選區，只把它調成新的比例（中心不變）；要重新置中請按「中央套用」。在框外不小心點一下不會丟掉原本的選區，蓋滿整張照片的選區等於沒有裁切。

旋轉提供左右 90°、任意角度及水平／垂直鏡像。一般加強提供亮度、對比、飽和度及銳利化；「恢復原貌數值」會把這四項回到預設值。

清洗成果建議保持前後影像條件可比較，不把調色或修圖說成清洗效果。本版沒有 AI 放大、失焦修復或 AI 自動去背。

## 文字與 Logo

文字與 Logo 分別有位置、大小及不透明度設定。勾選顯示後，在「成品預覽」拖動物件本體移動，拖右下角縮放。

文字可用一鍵靠左下、置中、靠右下。位置百分比代表物件可移動的範圍，不是把文字中心硬放到畫布邊緣。Logo 等比縮放。

Logo 支援 PNG、JPG、WEBP，單張上限 10 MiB、1600 萬像素。Logo 圖檔本身只存在本次分頁，不會放進慣用版型 JSON。

每張照片各自決定是否「顯示 Logo」。載入 Logo 時只會在目前這張打開；其他照片請各自勾選，或到批次頁按「將目前通用設定套到勾選照片」。

## 隱私遮蔽

在原圖上拖曳畫遮蔽框，或按「新增框」。新畫或新增的框不會自動選取，這時「遮蔽方式」與「強度」設定的是下一個要畫的框，面板會寫明目前調整的對象。

要改已有的框，在照片上點一下它（或按清單的「選取」）：面板會顯示它自己的方式與強度，也可以拉四角縮放、按「複製選取」或「刪除」。只是拖動一個框不會選取它；點空白處或按「取消選取」可取消。

方式有全不透明實色、模糊、馬賽克。輸出時，遮蔽位置會隨圖片裁切與旋轉一起轉換，不會因批次處理被略過。馬賽克與模糊都畫在不透明底色上，透明背景的圖片不會透出原本的像素；又高又窄的圖（例如長截圖）輸出時，遮蔽不會比畫面上看到的更細。

輸出尺寸超過限制時，裁切與遮蔽頁仍顯示原圖、可以照常編輯；成品預覽會改顯示提示，請先到「尺寸壓縮」把尺寸調小。

請對姓名、電話、地址使用實色遮蔽；模糊與馬賽克不提供無法復原或識別的保證。畫面中的「查看原圖」會顯示未編輯照片，僅供核對，輸出仍然依照設定遮蔽。

每張最多 40 個遮蔽框。正式分享前，請放大檢查輸出檔案是否仍有可辨認個資。

## 標記圖卡

可增加箭頭、矩形框、圈選與圖上文字，設定顏色。上方的類型、顏色、文字與箭頭方向用於下一個新增的標記；按「新增標記」後在成品上拖曳位置。單張最多 40 個標記。

要改已有的標記，在圖上點一下它（或按清單的「選取」），面板會載入它的顏色與文字，再改顏色、文字、方向或拖右下角縮放；每個設定只改它自己那一項。

這些是成品排版，不是原圖分析。改了裁切或旋轉後，請核對箭頭是否仍指向正確地方。

## 勾選批次

左邊每張有勾選框，只有勾選的照片會輸出。點縮圖只是切換目前編輯照片。可先搜尋檔名，再按「勾選搜尋結果」；「取消全部」會取消所有勾選。

每張都保留自己的設定。先把某張調好，勾選其他照片，按「將目前通用設定套到勾選照片」，可統一尺寸、格式、調色及浮水印。各張裁切、遮蔽與標記不會被別張選區覆蓋。

按「輸出勾選照片 → ZIP」。批次最多 80 張、合計輸出上限 256 MiB。輸出順序與照片清單相同；不同資料夾的同名照片會在檔名加上資料夾名稱，其餘重複才加編號。ZIP 附 `export_report.json`，報告包含成功／失敗、來源路徑、尺寸、bytes、局部編輯數與警告原文；報告含原檔名與資料夾名稱，分享前請確認沒有個資。

處理中可按畫面下方的「停止」（單張輸出與容量計算也可以停止），會在目前這一步完成後停止，不會產出不完整的 ZIP；停止後清單會註明這些項目都沒有下載。批次不修改原始檔案。

## 工具箱慣用版型

先調整好目前照片的通用設定，再到「慣用版型」輸入名稱，按「儲存目前通用設定」。最多 12 組；同名會先詢問覆寫。

會儲存尺寸、格式、品質、一般加強、文字、Logo 位置等通用參數；不儲存照片、Logo 圖檔、旋轉與鏡像、裁切、遮蔽或標記。套用版型不會改變照片的旋轉。

6.2.1 之前儲存的版型若帶有「顯示 Logo」，載入後會改為不顯示，需要時請在照片上勾選。在另一個分頁儲存或刪除版型時，已開啟的分頁會跟著更新清單。

可匯出／匯入 JSON 備份。這是圖片工具箱自己的版型，與對比工作區的慣用版型不同。舊對比版型仍在原工作區使用。

本機 HTML 的 localStorage 儲存方式可能依瀏覽器和檔案位置不同而改變。清除網站資料、換瀏覽器或檔名後不能假設版型仍在；請先匯出 JSON。若看到「僅暫存分頁」，務必在關閉前匯出。

## 與對比工作區搭配

單張修整完成後可按「加入對比素材」。程式會產生一張已處理的 PNG 加入照片清單，原圖仍保留。回對比工作區後，把新圖指定為洗前或洗後即可。

原對比工作區的 WEBP / PNG / SVG、標題、店名、背景橫條、批次對比、旋轉鎖定、安全框、FB / IG 比例模擬沿用。SVG 是內嵌 PNG，不是可拆開編輯的向量稿。

對比工作區「02 個別照片大小與位置」新增每張照片的「旋轉 °」欄位與 ↶ 左轉 90°／↷ 右轉 90° 按鈕；旋轉後，完整保留模式會縮小照片以免被裁到，填滿模式會放大裁切；同高版型與自動高度會依旋轉後的長寬重新配置。雙擊照片可一併重設旋轉。

照片清單（對比工作區與工具箱）每張都有「移除」按鈕，只從清單移除、不刪原始檔。若該照片已在批次組合或在工具箱有裁切／遮蔽／標記，會先詢問。移除會一併拿掉它的對比指定與批次組合；按「上一步」可整張復原（含工具箱編輯）。能復原它的步驟用完，或按「清空」後，才真正釋放。

在觸控螢幕上，對比畫布可用單指拖曳移動照片、雙指捏合縮放（以兩指中點為中心，也能邊縮放邊平移）。放開一指後，留在螢幕上的那一指可以繼續拖曳，再放回第二指可以繼續縮放；手指全部離開後才記為一步，可用「上一步」復原。

## 專案檔：保留照片與編輯進度

按照片清單下方（工具箱在清單上方）的「儲存專案檔」，瀏覽器會下載一個 `.enproj` 檔。下次按「開啟專案檔」選它，就能回到同樣的狀態繼續做。

專案檔包含：原始照片、洗前／洗後指定、畫布與文字設定、每張的位置／縮放／旋轉、批次組合與勾選、工具箱每張照片的通用設定／裁切／遮蔽／標記、批次勾選、Logo，以及單張輸出檔名、批次輸出格式與工具箱的檔名前綴。HEIC 照片存的是原始檔，不是轉換後的圖。

不包含：兩種慣用版型（仍存在瀏覽器，請另外匯出 JSON）、上一步／下一步的操作歷史、搜尋欄等畫面狀態。

開啟專案檔會取代目前分頁的照片與編輯，開啟前會先詢問。工具會先檢查整個檔案（大小、每個項目的 CRC、欄位型別與數值範圍），有任何一項不合格就整份拒絕，目前的內容不會被動到。

照片也是先解碼、確定能顯示才取代目前內容。全部都無法顯示時（例如專案裡全是 HEIC，而這台電腦的工具少了 `vendor` 資料夾）目前的內容原封不動；只有部分無法顯示時，會先說明有幾張，再問是否仍要取代。把單一個 `.enproj` 檔拖進照片清單也能開啟。開啟後，輸出檔名、批次格式與檔名前綴會換成專案檔裡的內容，搜尋欄會清空。在記憶體較大的電腦存的專案，照片合計可能超過另一台裝置的上限；超出的照片會略過並先詢問。

專案檔是不壓縮的 ZIP。請不要用其他軟體重新壓縮或加密，否則無法開啟。上限約 288 MiB。輸出尺寸超過限制的設定也會原樣存入，不會因此不能儲存。它內含原始照片，請當成客戶資料保管，不要上傳到公開的 GitHub repo。

還有沒輸出、也沒存成專案檔的工作時，關閉或重新整理分頁會跳出瀏覽器的確認視窗。每一份工作各自計算：對比圖在輸出後、批次組合在成功輸出 ZIP 後、工具箱的照片在輸出該張（單張或批次）後就視為完成，之後再修改會重新提醒；存成專案檔則全部視為已保存。

只是加入照片、切換照片、勾選或預覽批次組合不會觸發。這只是提醒，不會替你保存任何資料。

## 快捷鍵

| 按鍵 | 工具箱操作 |
|---|---|
| Ctrl + Z | 上一步 |
| Ctrl + Y / Ctrl + Shift + Z | 下一步 |
| Delete / Backspace | 刪除選取的遮蔽或標記 |
| Ctrl + D | 複製選取的遮蔽框 |
| 方向鍵 | 微調選取的裁切、遮蔽或標記 |
| Shift + 方向鍵 | 較大幅度微調 |
| Esc | 回對比工作區；處理中需先等待，或按下方的「停止」 |

在文字、數字輸入欄內，Delete 和方向鍵保留原本的輸入行為，不會誤刪遮蔽框。焦點在勾選框、滑桿、下拉選單或顏色欄時，Ctrl + Z、Ctrl + Y 與 Esc 一樣有效，方向鍵與 Delete 則留給該控制項。連續用鍵盤調同一個滑桿只算一步。

## 保存與限制

照片和工作內容只在目前分頁。切換照片會保留各自設定，但關閉或重新整理後不保留。要保留進度請用「儲存專案檔」；慣用版型不是完整專案保存。

單張輸入上限 50 MiB、6000 萬像素；整批來源上限 256 MiB、合計 1.2 億像素與 256 張。記憶體 8 GB 以上的電腦使用 Chrome 或 Edge 時，合計上限是 2.4 億像素，大約 19 張 1200 萬像素或 9 張 2400 萬像素的照片；手機、平板與其他瀏覽器維持 1.2 億。最終輸出單邊上限 8192 px、總像素 2000 萬。設定 JSON 上限 1 MiB。

支援 JPEG、PNG、WEBP、BMP，GIF 固定載入時一幀，以及 iPhone 的 HEIC／HEIF（見下一節）。TIFF、SVG 等不直接匯入，請先轉換。工具箱沒有 AI 自動去背或網頁轉圖片。瀏覽器無法輸出 WEBP 時（例如 Safari），工具箱預設改用 JPG，對比工作區的批次格式改用 PNG。

只有故意點選正式網站或 GitHub 連結才會離開工具；圖片編輯流程沒有外部 API、CDN、模型下載或主動網路傳輸。HEIC 解碼元件是隨工具附上的本機檔案，不會連線。仍需注意瀏覽器擴充套件、電腦本身與自行分享的輸出檔安全。

## iPhone 的 HEIC 照片

HEIC 是 iPhone 預設的照片格式。把 `.heic` 或 `.heif` 檔和其他照片一樣加入即可，拖放、資料夾、工具箱的「加入照片」與專案檔都適用。

Safari 17 以上由瀏覽器自己解碼。Chrome、Edge 與其他瀏覽器不會顯示 HEIC，工具會改用隨附的解碼元件：`vendor` 資料夾裡的 `heic-decoder.html`。每張約需 1 秒到數秒，畫面下方會顯示「正在解碼 HEIC」的進度。

`vendor` 資料夾必須和 `index.html` 放在同一層。只複製單一個 HTML 到別處時，HEIC 會被略過，訊息會請你把資料夾放回去；JPEG、PNG 等其他照片不受影響。這個狀況會記到重新整理頁面為止，放回資料夾後請重新整理。

直拍的照片會依檔案裡的旋轉資訊轉正。iPhone 的 Display P3 色域會換算成一般螢幕與輸出使用的 sRGB，操作紀錄會註明；其他少見的色彩描述檔不換算，也會註明顏色可能略有差異。帶透明的 HEIC 保留透明。HDR 增益圖、深度圖、原況照片的影片與同一檔案內的其他張不會使用。

解碼只是讓瀏覽器能顯示這張照片。照片本身仍是原始的 HEIC：清單顯示的是原檔大小，專案檔存的也是原檔。

解碼元件是第三方軟體 libheif（LGPL-3.0），授權說明在 `vendor/THIRD_PARTY_NOTICES.md`。它在沙箱框架裡執行，只拿得到正在解碼的那一張照片，沒有網路，也碰不到工具、瀏覽器儲存空間或其他檔案。

## 檔案在哪裡

輸出會交給瀏覽器下載，通常在瀏覽器設定的下載位置。按 Chrome / Edge 的下載清單查看；不是 BAT 版原來的 `output` 資料夾。

這個 ZIP 內已包含 `index.html`。要更新 GitHub Pages，請看同資料夾的 `DEPLOYMENT.md`。不要只把整個 ZIP 上傳，Pages 不會把 ZIP 自動解開當成工具。

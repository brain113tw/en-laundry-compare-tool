## 環境與限制

Linux Chromium headless（工具箱檢查修正版重跑：Chromium 153.0.8010.12）/ Python Playwright。HTML 使用 page.set_content，因執行環境限制本機導航；沒有弱化正式程式的 CSP。下載由實際編碼產生 Blob，測試直接擷取 Blob 驗證格式、尺寸、位元組數與 ZIP CRC，未操作使用者 Windows 另存新檔視窗。

沒有驗證實體手機或平板的觸控、Safari 對 HEIC 的原生解碼、Windows 原生檔案總管拖放、file:// 導覽、Safari/Firefox、GitHub Pages 實際部署、全部 EXIF／色彩描述檔或所有惡意圖片。localStorage 寫入被拒絕時的明確提示有測，但未做關閉重開之後的持久儲存端到端驗證。

新舊工作區啟動、分享照片清單、拖入事件、等比例及90度旋轉、裁切、裁切後旋轉之遮蔽座標、全不透明遮蔽、模糊與馬賽克確實改變遮蔽區像素、遮蔽強度不受裁切影響、瀏覽器不支援 canvas filter 時模糊遮蔽仍生效且調色滑桿停用、超大尺寸存版型不拋例外、匯入版型名稱去除控制字元、對比照片旋轉改變版面與輸出並可復原與夾限、填滿模式在 45° 旋轉仍填滿格子、單張移除可用上一步整張復原並重置該側位置、工具箱移除可用鍵盤操作、四角拉伸、鎖定裁切比例、文字浮水印拖曳、Logo載入、Undo/Redo、各張局部編輯、數值0、平坦區銳化亮度、容量不可達警告、批次依勾選輸出且保留遮蔽、JSON白名單與容量限制、CSP雜湊和網路限制、1366px及390px水平版面，以及處理過的PNG回到比較素材清單。

專案檔：存檔為合法的不壓縮 ZIP 且 CRC 正確、照片位元組原樣保存、重新開啟後設定／位置／批次／工具箱編輯／勾選／Logo 完全相同且輸出逐像素一致、由另一個 ZIP 工具重寫（不壓縮）仍可開啟、拒絕取代時維持原狀；CRC 不符、重新壓縮、截斷、非 ZIP、缺項目、型別錯誤、未知引用、危險鍵、巢狀過深、超限尺寸、非法遮蔽或標記等 23 種檔案整份拒絕且工作階段不變；超界數值夾限、無法解碼的照片略過並丟棄引用、超限尺寸不會被寫入專案檔。觸控：以真實觸控輸入驗證雙指放大縮小、置中、夾限、一步復原、單指平移、拖曳標籤時第二指不縮放。HEIC：真實 HEIC 檔的辨識、AVIF 不被當成 HEIC、改名的 JPEG 以簽章拒絕、無法解碼時的專屬提示。未儲存提醒的各種狀態。

## 可重跑的檔案

`tests/check_compare.py`、`tests/check_toolbox.py` 與 `tests/check_features.py`（專案檔、觸控、HEIC、未儲存提醒；使用 `tests/fixtures/sample.heic`）是開發者測試，需要 Python、Playwright、Pillow 及 Chromium。一般使用者只開 HTML，無須這些環境。
